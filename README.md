# 好きな惣菜発表ドラゴン

好きな食べ物を発表しながら、Git / GitHub の共同開発を練習する場所です。
惣菜に限らず、好きな食べ物なら何でもOK。一行でも、たっぷり語ってもOKです。

## 参加方法

1. このリポジトリを clone する（事前に案内された招待を承認してください）。
2. 自分の作業用ブランチを作る。例：`git switch -c feature/自分のID`
3. `foods/` に好きな食べ物の Markdown ファイルを追加するか、既存の食べ物ファイルに自分の一言を追記する。
4. 変更を commit して、自分のブランチを push する。
5. GitHub で `main` に向けた Pull Request（PR）を作る。
6. レビュー・マージ後に `main` に戻り、`git pull` でみんなの変更を受け取る。

新しいファイル名の例：`foods/プリン-自分のID.md`。同じ食べ物があっても大丈夫です。
既存ファイルに追記する場合は、ほかの人の文章を残して、自分の名前やIDを添えてください。
`main` への直接 push と、自分の判断でのマージはせず、PRを送るところまで進めてください。

## 書き方

形式は自由。これだけでもOKです。

```markdown
# プリン

固めのプリンが好きです。 — 自分のID
```

見本： [唐揚げ](foods/唐揚げ.md) ／ [ハンバーグ](foods/ハンバーグ.md)

PRのタイトルも「プリンを追加」「唐揚げへの愛を追記」くらいで大丈夫です。

## この実習のゴール

立派な文章を書くことより、自分の変更をPRで届けること。
好きな食べ物を一つ書けたら、まずは送ってみましょう。
